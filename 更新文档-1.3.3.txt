【ElainaChat Open v1.3.3 更新】

ElainaChat Open v1.3.3 更新文档

开源 BYOK 双端版（安卓 App + PC 客户端）。本次与正式版同步新增「聊天平台接入」。

■ 一、设置页新增「聊天平台」分段

参考 AstrBot 的平台适配层，先接三条纯出站的路：

- QQ（OneBot v11 正向 WS）：连 NapCat / Lagrange / go-cqhttp 的 WS 服务，收消息、回消息；
- Telegram Bot：Bot API 长轮询（不需要公网回调）；
- 通用 Webhook（自建桥）：GET 拉取 {messages:[…]}、POST {to,text} 回复。

不监听端口、不经云端；密钥只存本机，日志里打码。

■ 二、消息走同一条对话链路

平台消息 → handleUserInput（点「发送」用的同一个函数）→ 回复发回平台。
人设 / 记忆 / 简洁化 / 多段回复与手动聊天完全一致。

- 会话归属默认「每个来源单独一间」（标题如 [Telegram] tguser），可切「都用当前对话」；
- 「允许的来源」留空 = 全部允许；
- 群聊默认只在被 @ 或带触发前缀时才回；
- 超长回复自动分条；面板有状态点、连接/断开、最近事件日志。

开源版同样只需要自己的模型 API Key（BYOK），平台接入不引入任何云端依赖。

■ 三、版本

- package.json 1.3.2 → 1.3.3。

■ 四、验证

无头浏览器 + 三个假平台跑真实页面 14/14 全过（同正式版那一套用例）。
