✦ 用户身份设定

设定「用户是谁」，对话中会按这些信息称呼与对待你。每个对话可在「当前会话角色卡」里单独覆盖。

角色设定快捷槽位

把当前角色卡存为快捷槽位；重复设定会自动去重并把旧槽位移到最前。点「选择设定」可快速套用。

✦ 对话模型（多 API 格式）

请求从当前设备直接发给所选服务商，不经过作者服务器。Android Key 使用系统 Keystore 加密；Web Key 仅保存在当前标签页会话。

✦ 语音输出（多服务商）

填写新控制台 API Key 时使用 V3 大模型接口；只填写旧控制台 App ID 与 Access Token 时使用 V1 小模型接口。1.0 与 2.0 音色不能混用。

默认先显示文字，语音在后台准备；同步模式会等语音真正开始时再显示回复。

开源版不内置任何音色 ID，也不会把请求发给作者。MiniMax 需填写自己的音色 ID；豆包和千问可使用系统音色。

✦ 语音输入

Android 没有系统级浏览器识别时，可用自己的 DashScope Key 直连 qwen3-asr-flash；留空不会调用阿里服务。

✦ 记忆

记忆整理会调用模型把当前对话总结为日记、约定、用户偏好、计划、动机与关键记忆，并注入后续回复的提示词。也可随时点击顶部金句旁的「整理记忆」手动触发。

可把记忆备份为 JSON / 文本 / 二维码，之后可导入合并或覆盖。

✦ 日志与错误报告 (构建 ' + MEMORY_BUILD_TAG + ')

记录启动信息、点击操作、插件调用与错误。遇到问题请先「导出日志」把文件发给开发者。
